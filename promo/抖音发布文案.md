### 正文（方案 A：解决痛点型）

```
手机相册是不是也这样：想找一张照片翻十分钟，截图、表情包、实拍全堆一起。

我做了个本地相册整理工具「卡包相册」，不联网、不改原图：
· 长按进入多选，直接拖到左侧卡包，松手就归档
· 一张照片可以同时放进多个卡包（旅行 / 家人 / 工作）
· 卡包内还能自己拖顺序，像翻实体相簿
· 删了先进垃圾桶，能恢复；确认后才彻底删除
· 整个卡包一键分享给朋友
· 视频、动图、实况都能筛选、能播放

安卓手机装好就能用。需要的话评论区说一声。
```

### 正文（方案 B：开发者自述型）

```
自己做的相册小工具，起因是我手机里两万多张照片，怎么整理都乱。

想了个「卡包」的思路：左边一排卡包，右边照片墙，长按照片往卡包上一拖就分好类了，比一层层点菜单快很多。

几个我觉得好用的点：
· 一张照片能进多个卡包，不会再出现「这张到底放哪个包」的纠结
· 卡包里的顺序可以自己拖，排成相簿的样子
· 删除先进垃圾桶，不怕手滑
· 全部本地处理，没有网络权限，照片不上传
· 不喜欢的照片可以直接从卡包「移出」，文件还在

安卓机可用，想看的人评论区留言。
```

### 录屏建议

1. 用真机录屏，先把示例照片换成本人真实相册（打码敏感内容），真实感更强；
2. 录屏时打开「触摸显示」，观众能看到手指轨迹；
3. 拖动动作放慢一半再用剪辑软件加速到 1.5 倍，卡顿感会消失；
4. 前 3 秒必须出现「拖动归档」这个动作画面，这是最抓人的点；
5. 背景音乐选热门纯音乐，音量压到 30% 以下，别盖住口播。

## 四、发布节奏与合规提醒

### 建议节奏

- 第 1 条：图文 9 图（主推方案），晚 19:00–21:00 发；
- 第 2 条（隔 1–2 天）：同一个功能的竖屏录屏，15 秒，标题换成「拖动归档全过程」；
- 第 3 条：单独讲「垃圾桶恢复」或「一张照片进多个卡包」这类差异化功能，更容易被收藏。

### 合规要点（重要）

1. **不要在标题、正文、口播里写下载链接、网盘地址、微信号、QQ 号**，抖音会判定站外导流，轻则限流重则删稿；
2. 引导统一放在**置顶评论**，让用户评论关键词后私信发送；
3. 不要写「永久免费」「最强」「第一」等绝对化用语，可以用「自己做的」「个人作品」；
4. 提到「安卓安装包」时说明需要允许安装未知应用，避免用户装不上来评论区骂；
5. 明确说「暂不支持 iPhone」，减少无效私信（你对 iOS 的疑问在这条里也能提前回答）；
6. 应用内截图里如果出现真人照片，发布前确认是本人或已获授权，示例图建议用风景/食物类。
